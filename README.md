# Isabelle & Bruno — Save the Date 💍

Site exclusivo de **Save the Date** para o casamento de **Isabelle & Bruno** — 13 de Janeiro de 2029.

## ✨ Recursos
- **Brasão Animado (SVG)**: Monograma clássico com letras entrelaçadas, fita caligráfica, estrelas cintilantes e órbita de luz celestial.
- **Efeito 3D Interativo**: Brasão com inclinação 3D dinâmica ao movimento do mouse no desktop.
- **Animações Fluidas no Scroll**: Revelação progressiva de palavras e frases conforme a rolagem da página.
- **Contagem Regressiva em Tempo Real**: Dias, Horas, Minutos e Segundos com estilo glassmorphism dourado.
- **Design Responsivo**: Adaptado para computadores, tablets e smartphones.

## 🛠️ Tecnologias
- HTML5 Semântico
- CSS3 (Vanilla, Animações, SVG Filters & Gradients)
- JavaScript Vanilla
